# ASE Crimson Chat — 20 Built-In MP3 Sounds Enabled

This download is ASE Crimson Chat v3.2 with the original built-in MP3 sound files included and enabled for new installations.

Open TOOLS → SOUND STUDIO. Each of the 20 events has a built-in MP3 and lets you upload your own, play it, download it or reset it to the default. Sound settings are saved locally per browser.

The previous combined RP Hub had muted these defaults; that is corrected in the separate updated RP Hub download. Existing devices that manually disabled sounds may need to toggle ENABLE SOUNDS back on.

Deploy with Node 18+, `npm install` and `npm start`. This standalone ASE uses its own `/` route rather than an RP hub launcher.
