ASE v3.1 / Quick Mark Suite

This version builds on ASE 3.0. See README.md for original setup.

New: quick/preset markers, priority 1 or 2, marker colors, temporary expiration,
voice notes, in-browser filtered photo/video markers, draggable owned markers,
zoom controls with progressive detail and lower-priority preview cards, marker history,
three customizable favorite tools, map previews in chat, timestamps.

All public and private map permissions are verified by the server. Room events and
media are transient: this demo stores them in memory only, and markers owned by
a departing member are removed, as in previous versions. Browser-captured Heat and
Night Vision are simulated color grading, not infrared or thermal sensors.


## Version 3.2
- Cluster marker pins at low zoom, tap cluster to expand.
- Priority 1 alert event cue.
- Draw and save creator-owned polygon areas with priority, color and expiry.
- Find marks by note/creator/priority within current chat only.
- Sound Studio with 20 editable event MP3s, custom MP3 imports, built-in sound pack, and a browser-based MP3 composition/download tool.
- Improved map-space layout in landscape orientation.
